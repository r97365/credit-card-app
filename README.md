# Credit Card Rewards

手機優先的信用卡回饋追蹤網站，設計為 Safari 加到主畫面使用。

## 第一版已包含
- Wallet 式信用卡堆疊選卡
- 每月總刷卡上限與進度
- A/B/C 等回饋活動同時存在、獨立計算
- 回饋金上限 / 消費上限 / 無上限資料模型
- 整月加總計算 / 單筆計算再加總
- 無條件捨去 / 四捨五入
- 交易整筆排除回饋
- 每個活動的日期區間
- 預估總回饋 + 實質回饋率
- Tip ⓘ 點擊顯示
- Supabase-ready 資料結構
- PWA manifest

## 開發
```bash
npm install
npm run dev
```
